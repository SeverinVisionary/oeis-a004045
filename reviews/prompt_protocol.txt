METHODOLOGY REQUEST. I do not want you to search this time. I want you to design
the search protocol, so that a second person can execute it and we can both say
afterwards how much of the space was actually covered.

CONTEXT
The quantity is K(8,1,2): minimum size of a set C of binary words of length 8
such that every word of F_2^8 has at least two members of C within Hamming
distance 1. OEIS A004045(8), first unknown term. Published record
59 <= K(8,1,2) <= 64 (lower bound Krotov-Potapov arXiv:1902.00023 Thm 6(a) 2020;
upper bound Ostergard tabu search 1995).

A stock 0/1 integer program over 256 binary word-variables, run in HiGHS and in
SCIP, refutes M = 57, 58, 59 and 60 in seconds to minutes, and does not settle
61 or 62 in six hours. If correct that gives K >= 61, two rungs past the
published bound, for about five minutes of laptop time. I distrust a result that
cheap.

WHAT I WANT FROM YOU

A. A SYSTEMATIC PROTOCOL for establishing whether a computational result in
   extremal combinatorics is already known. Not advice -- an ordered, executable
   checklist, where each step names the specific resource to query and the
   specific query string or identifier to use, and states what a hit and a miss
   each mean. Design it around the failure modes that actually hide results:
     - the same object under a different name in a different subfield;
     - values that live only in a thesis table, a technical report, a conference
       abstract, or a table on a personal homepage;
     - values computed but never written up, visible only in source
       distributions, README files, solver logs, mailing lists, or OEIS
       correspondence;
     - a maintained table that has been silently updated since the last paper;
     - non-English literature, and pre-1995 work that predates indexing;
     - the result being a corollary of something published in a different
       parameterisation, so that no one ever stated the number.

   resources, in the order I should hit them, with the exact search strings,

C. THE SYNONYM MAP. Enumerate every name and notation under which

E. EVIDENCE STANDARD. Distinguish prior art in print from prior art in
